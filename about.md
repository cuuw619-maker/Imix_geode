# Imix

Imix is a lightweight Geode mod for Geometry Dash 2.2081, built for Geode 5.10.1.

## What it does

Imix adds a dedicated in-game menu that can be opened from the main menu and pause screen. The menu provides a base for future Imix features and is organized into sections:

- Smart StartPos — the initial section for spawn-position tools.
- Player — reserved for player-related options.
- Visual — reserved for visual and interface options.

## Status

The current release is the foundation of the Imix interface. More functionality will be added to the sections as development continues.
